# Webgrafía — Semana 08

| Recurso | Descripción |
|---|---|
| [PlantUML: diagrama de componentes](https://plantuml.com/component-diagram) | `component`, `interface`, interfaces provistas y requeridas, puertos y agrupaciones |
| [PlantUML: diagrama de despliegue](https://plantuml.com/deployment-diagram) | `node`, `artifact`, anidamiento y estereotipos; lista también formas que no son UML (`database`, `cloud`) |
| [PlantUML: diagrama de clases, paquetes](https://plantuml.com/class-diagram) | Sección de paquetes: `package { }`, estilos y dependencias entre paquetes |
| [UML 2.5.1 (OMG)](https://www.omg.org/spec/UML/2.5.1/) | Especificación vigente; componentes en el capítulo 11.6, paquetes en el 12 y despliegue en el 19 |
| [UML Distilled — Martin Fowler](https://martinfowler.com/books/uml.html) | Libro de referencia breve; sus capítulos de paquetes, despliegue y componentes explican cuándo merece la pena dibujar cada uno |
