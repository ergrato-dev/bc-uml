# Webgrafía — Semana 10

| Recurso | Descripción |
|---|---|
| [UML 2.5.1 (OMG)](https://www.omg.org/spec/UML/2.5.1/About-UML) | Especificación vigente: la referencia cuando en la revisión se discute si algo es UML válido |
| [Google Engineering Practices: The Code Reviewer's Guide](https://google.github.io/eng-practices/review/) | Cómo revisar el trabajo de otro y cómo responder a una revisión. Cambia "código" por "modelo" y casi todo sigue valiendo |
| [What to look for in a code review](https://google.github.io/eng-practices/review/reviewer/looking-for.html) | La lista de qué mirar, de lo general a lo concreto: el mismo orden que la lista de revisión de la teoría |
| [PlantUML: diagrama de clases](https://plantuml.com/es/class-diagram) | Comentarios `'`, notas y estereotipos: lo que usas para dejar el porqué de cada decisión en el diagrama |
| [UmlAsSketch — Martin Fowler](https://martinfowler.com/bliki/UmlAsSketch.html) | Por qué un modelo se usa para comunicar decisiones y no para documentarlo todo: el espíritu de la defensa |
