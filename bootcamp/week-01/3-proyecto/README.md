# Proyecto Final — Week 01: Sistema de Gestión de Biblioteca

> ⏱️ Tiempo estimado: **30-40 minutos** | Entregable: `sistema-biblioteca.puml`

## 🎯 Objetivo

Implementar el diagrama de clases completo de una Biblioteca Municipal,
aplicando todos los conceptos de la sesión: visibilidad, relaciones,
multiplicidades, clases abstractas e interfaces.
