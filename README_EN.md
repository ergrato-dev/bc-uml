## 📋 Description

Intensive 2-session UML bootcamp (~10 hours) designed for software developers and systems analysts.
Learn the most important UML diagrams with real-world examples and hands-on exercises.

> **Study time**: ~5 hours/week — Structured to respect your schedule.

### 🎯 Learning Outcomes

By the end of this bootcamp, you will be able to:

- ✅ Design class diagrams with all 6 relationship types
- ✅ Capture requirements with use case diagrams
- ✅ Model interactions with sequence diagrams
- ✅ Document object lifecycles with state machines
- ✅ Design business processes with activity diagrams
- ✅ Specify architecture with component and deployment diagrams
- ✅ Communicate software designs professionally
